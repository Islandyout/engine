# F89 — Remove GATEBREAKER and VELOCITY

The two big example games slowed browser tests, CI and merges while the engine is being reorganised. They are removed; the City Template stays as the living-worlds example.

- **Removed**: `games/gatebreaker`, `games/my-games/velocity`, `examples/gatebreaker`, `tools/gatebreaker`, `tools/velocity`, their browser tests (`gatebreaker*.cjs`, `velocity*.cjs`) and unit test, the `npm run gatebreaker` and `npm run velocity` scripts, and their CI steps.
- **Kept**: every engine feature they drove, all models and audio, the generators for the other examples, their Lua as reference in `examples/scripts/`, and their design notes in `docs/lessons/`. See [docs/lessons/README.md](../lessons/README.md).
- **Moved**: the scene helpers `tools/gatebreaker/kit.ts` to `tools/lib/scene_kit.ts`, because `tools/city` imports them.
- **Changed**: `tests/browser/city.cjs` no longer reads VELOCITY's scene for a HUD line; it builds a plain text UI.
- **Recover**: the last commit with both games is `3ebed2a`.
