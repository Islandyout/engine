# F92 — `main.ts` split into `editor/app/*` (0.90.1)

`apps/editor/src/editor/main.ts` (6,980 lines, one `startEditor()` closure) is now 21 parts under `apps/editor/src/editor/app/` plus a ~2,000-line `main.ts` that creates the shared state and wires events.

- Each part (`environment`, `cameras`, `postfx`, `audio`, `heldGuns`, `effects`, `assets`, `space`, `scriptHost`, `explorer`, `input`, `saves`, `animation`, `runtimeSync`, `loot`, `sceneObjects`, `panels`, `uiActions`, `vehicles`, `frame`, `hud`) exports `installX(C)` which declares its functions and registers the shared ones on `C`.
- `app/context.ts` holds the `Ctx` type (everything parts share: state, objects, helpers), the `Runtime` type and the local types. Mutable state read by more than one part lives on `C`.
- No behaviour change. Unit tests, typecheck and the browser tests (inventory, equip, editor_touch, editor, loot_ui, city, fps) pass.
