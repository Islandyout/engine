# F90 — Widget-only HUD, recipes, requires hints (0.89.0)

The start of the engine upgrade ([UPGRADE_DESIGN.md](../UPGRADE_DESIGN.md)). Features built on top of each other no longer replace each other's UI.

- **Nothing draws HUD by itself.** Removed the implicit gun HUD (crosshair, ammo, health), loot prompt/feed/card, fighter bars, skill slots (now with the Fighter bars widget), floating enemy health bars, capture hint, vehicle and flight instruments. Each is a UI-kit widget; no widget, no HUD. The screen-reader text mirror (`#hud-text`) is unchanged.
- **New widgets**: Fighter bars, World health bar, Hint, Vehicle instruments, Flight instruments. **`UI.source`** (Player, an entity name, or `@target`) for Health and Fighter bars.
- **Old scenes migrate on load** (`scene/hudMigration.ts`): the widgets the old HUD drew are added as `HUD <widget>` entities in the scene's style, and the log lists them. Saved scenes carry `hud: "widgets"`; templates ship with their widgets.
- **`Pickup.onPickup`**: per-item UI to show when it is taken (`<UI entity name>: <text> | <seconds>`).
- **Equip fix**: a fighter or player without a `Weapons` component now gets the held-weapon pose, so a melee weapon picked up in Play is drawn in the hand immediately (it stayed invisible until a weapon slot was selected). `tests/browser/equip.cjs` (fails without the fix).
- **Recipes** (Hierarchy > Recipes...): ten kinds of thing (players, enemies, cars, ship, pickup, container) with their components and, optionally, their HUD widgets.
- **Inspector**: cards grouped under the Add-component groups; **Requires** hints (`Melee` needs `Health` and `Collider`, ...) with an "Add" button, and a warning when removing a component others on the entity need.
- **Tests**: `hud.test.ts` (migration, recipes, requires, onPickup); template and demo entity counts now include their HUD widgets (an intended change, not a loosened check).

Not in this change (needs the C++ runtime and a wasm build): the `Inventory` component, `inventory.*` Lua API, slot capacity and weight, equipment slots, `main.ts` split.
