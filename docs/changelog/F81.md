# F81 — GATEBREAKER: running legs and no T-poses (0.81.0)

## Fixes

- **Fighters running without leg movement**: the hunter and the goblins slid along the ground when they ran. Their models carry no animations of their own, and the combat clip library had no run clip, so at running speed the pose froze.
  - The library now also loads the Mannequin's idle, walk, run and sprint clips, which use the same skeleton.
  - Fighters on these rigs run with their legs moving.
- **T-poses in the prologue**: characters that aren't fighters, such as the prologue hunter and goblins, stood in their bind (T) pose for the same reason.
  - A rig with no clips of its own now plays the library's idle clip.
  - An authored `AnimationState.clip` is used instead when one is set.

## For people working on the engine

- `combatView.loadCombatClips` merges `locomotionClipsPath` (`kit/people/mannequin_f.glb`) into the library: idle, walk, run and sprint.
- A unit test checks that the library has every clip a stance names, and the locomotion.
