# F102 Desktop app

`apps/desktop`: an Electron app that serves the built editor and games from local files and draws on the laptop's graphics card.

- A GPU report (Help > GPU status) and a warning when the page is software-rendered.
- A control port on 127.0.0.1 (bearer token in `~/.config/btai-desktop/control.json`, browsers refused) with an MCP server (`mcp.mjs`) and a CLI (`btai.mjs`) so an AI can load games and scenes, run authoring commands, play, press keys, take screenshots and read the page log.
- The editor exposes `window.btai` only when the user agent says `BTAIDesktop`.
- `build_game_app.mjs` packages one game as a standalone AppImage and .deb that opens full screen.
- Unknown game names are refused with the list of games, not mapped to something else.

Verified under Xvfb (software rendering): control calls, MCP tools, a packaged game launching. Frame rate on a real GPU is not measured.
