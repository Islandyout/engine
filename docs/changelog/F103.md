# F103 Eden

`games/my-games/eden`: Adam and Eve, two characters whose minds run on a Supabase project, living in a garden (river, fruit grove, meadow, overlook, resting hollow, two landmark trees).

- A Supabase cron function (`eden-tick`, every 3 minutes) decides each character's action and location; the page polls it (`apps/editor/src/editor/app/edenAgents.ts`) and drives `tools/eden/lua/{adam,eve}.lua`.
- A panel (Eden scenes only) lets the player speak to them and say "let there be..." to add a Deer, Fox, Alpaca, Oak Tree, Pine Tree, Bush or Rock; anything else is refused with the list.
- "Let there be" ignores a leading article ("a deer", "let there be an oak tree").
- The scene is generated by `tools/eden/build_eden.ts`.

Known gaps: no tests for the poll or the panel; the Speak and Create tables accept writes with the public key, so they need server-side limits; the scene defines no camera.
