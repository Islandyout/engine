# 10 — 2D

Manual: <https://docs.unity3d.com/Manual/Unity2D.html>

## 1. Sprites

- **Sprite import**:
  - Texture Type Sprite (2D and UI). Sprite Mode (`SpriteImportMode`): Single, Multiple, Polygon.
  - Pixels Per Unit, Mesh Type (`SpriteMeshType` FullRect, Tight), Extrude Edges, Pivot, Generate Physics Shape.
  - Filter Mode Point for pixel art, and compression None.
- **Sprite Editor**:
  - Slicing: Automatic, Grid by Cell Size, Grid by Cell Count, Isometric Grid.
  - Pivot, border (9-slice), and **Custom Outline**.
  - **Custom Physics Shape**, **Secondary Textures** (normal and mask maps for 2D lights), and **Skinning Editor** (2D Animation).
- **SpriteRenderer**:
  - `sprite`, `color`, `flipX`/`flipY`.
  - `drawMode` (`SpriteDrawMode` Simple, Sliced, Tiled with `SpriteTileMode` Continuous or Adaptive), `size`.
  - `maskInteraction` (`SpriteMaskInteraction` None, VisibleInsideMask, VisibleOutsideMask), `spriteSortPoint` (Center, Pivot).
  - Material, sorting layer and order in layer.
- **Sprite Atlas** (v2):
  - Packs sprites, folders or textures. Include in Build, Allow Rotation, Tight Packing, Padding, Read/Write, mipmaps, platform overrides.
  - **Variant** atlases (scale) and late binding (`SpriteAtlasManager.atlasRequested`).
  - Sprite Packer mode: Disabled, Sprite Atlas V2 – Enabled, or Enabled For Builds.
- **SpriteMask**: a sprite or alpha cutoff with a sorting-range custom range. **SortingGroup** sorts a hierarchy as one unit.
- **Sorting**:
  - Sort order: **Sorting Layer**, then **Order in Layer**, then distance to camera.
  - Transparency Sort Mode (Default, Perspective, Orthographic, **Custom Axis**, e.g. (0,1,0) for top-down Y-sorting).
  - Sprite sort point.
- **Rendering** (6.3+): 3D Mesh and SkinnedMesh renderers can be drawn inside 2D URP scenes (the `RenderAs2D` module).

## 2. Tilemaps

- **Grid**: cell size, gap, **Cell Layout** (Rectangle, Hexagon, Isometric, Isometric Z As Y), cell swizzle.
- **Tilemap**:
  - Methods: `SetTile`, `GetTile`, `SetTiles`, `BoxFill`, `FloodFill`, `SwapTile`, `SetTileFlags`, `SetColor`, `SetTransformMatrix`, `CompressBounds`, `RefreshTile`.
  - Coordinates: `WorldToCell`/`CellToWorld`, `HasTile`, `cellBounds`, orientation and anchor, `animationFrameRate`.
- **TilemapRenderer**: sort order, mode (Chunk, Individual, SRP Batch), detect chunk culling bounds, mask interaction.
- **TilemapCollider2D**: often combined with a CompositeCollider2D to merge tiles.
- **Tile Palette window**:
  - Tools: select, move, brush, box fill, pick, erase, flood fill, rotate/flip.
  - Brushes: Default, GameObject Brush, Group, Line, Random, Prefab (2D Tilemap Extras).
- **Tile types**: `Tile`, `RuleTile` (neighbor rules), `RuleOverrideTile`, `AnimatedTile`, `IsometricRuleTile`, `HexagonalRuleTile`, and custom `TileBase` (`GetTileData`, `RefreshTile`, `StartUp`, `GetTileAnimationData`). The extra types come from the 2D Tilemap Extras package.

```csharp
// Procedural tilemap fill (illustrative)
public Tilemap map; public TileBase ground, wall;
void Generate(int w, int h) {
    for (int x = 0; x < w; x++) for (int y = 0; y < h; y++) {
        var n = Mathf.PerlinNoise(x * 0.1f, y * 0.1f);
        map.SetTile(new Vector3Int(x, y, 0), n > 0.55f ? wall : ground);
    }
}
```

## 3. Sprite Shape (`com.unity.2d.spriteshape`)

- **SpriteShapeController**: a spline with tangent modes (Linear, Continuous, Broken), corners, per-point height, sprite variant, fill.
- **SpriteShape Profile**: angle ranges → sprites, corner sprites, fill texture, and fill offset.
- **SpriteShapeRenderer**, plus collider generation (Edge or Polygon).

## 4. 2D Animation and PSD Importer

- **2D Animation**: skeletal sprite animation.
  - Skinning Editor: bones, geometry auto-generation, weights (auto and brush), visibility, sprite swap.
  - **Sprite Library Asset**, `SpriteResolver` for frame-by-frame or part swaps, and **Sprite Skin** deformation (Burst/Collections accelerated, GPU deformation in 6.x).
  - **2D IK**: Limb, CCD, FABRIK solvers.
- **PSD Importer** (`.psb`): imports layers as sprites, keeps the character rig, and creates a mosaic atlas and prefab.
- **Aseprite Importer**: imports `.ase`/`.aseprite` files as sprites, animations and tilemaps.
- **6.5**: a BlendShape API for sprites brings free-form cage-based deformation.

## 5. 2D Lights (URP 2D Renderer)

- **Light2D types**: Global, Freeform, Sprite, Spot (formerly Point; inner/outer radius and angle), and Parametric (legacy).
- **Light2D properties**:
  - Color, intensity, falloff and falloff strength, target sorting layers, blend style (Multiply/Additive, with custom blend styles in the 2D Renderer data).
  - Normal maps: quality and distance.
  - Volumetric intensity, shadows (strength and softness), overlap operation.
- **ShadowCaster2D**: self shadows, casting option, shape from sprite/collider/mesh. The **Composite Shadow Caster 2D** merges casters.
- **Sprite Custom Lit** shader graph. **Light Blend Styles**: up to 4. Custom 2D lighting and shadow APIs arrived in 6.5.
- **2D Renderer features**: Sprite Mask, Camera Sorting Layer Texture, Pixel Perfect.

## 6. Pixel Perfect

- **Pixel Perfect Camera** component (URP 2D): Assets Pixels Per Unit, Reference Resolution, Crop Frame (None, X, Y, XY, Stretch Fill), Grid Snapping (None, Pixel Snapping, Upscale Render Texture), filter mode, Run In Edit Mode.
- **Cinemachine Pixel Perfect** extension.

- **Samples**: Dragon Crashers (6.x), Happy Harvest, Gem Hunter Match.
