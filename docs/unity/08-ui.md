# 08 — UI and text

Manual: <https://docs.unity3d.com/Manual/UIToolkits.html> · UI Toolkit: <https://docs.unity3d.com/Manual/UIElements.html> · uGUI: <https://docs.unity3d.com/Packages/com.unity.ugui@2.0/manual/index.html>

Unity has three UI systems:

| | UI Toolkit | uGUI (Unity UI) | IMGUI |
|---|---|---|---|
| Model | Retained, web-like (UXML + USS + C#) | GameObject/Component based (Canvas) | Immediate mode (`OnGUI`) |
| Use | Editor UI (default) and runtime UI | Runtime UI, world-space UI | Editor tooling, debug overlays |
| Layout | Flexbox (Yoga) | RectTransform anchors + Layout Groups | GUILayout auto layout |

## 1. UI Toolkit

- **Documents and panels**:
  - **UXML** holds the structure (templates, `<ui:Template>`/`<ui:Instance>`, attribute overrides, slots). **USS** holds the styling. C# builds `VisualElement` trees.
  - At runtime a `UIDocument` component references a `PanelSettings` asset. Panel settings: scale mode (Constant Pixel Size, Constant Physical Size, Scale With Screen Size with match), sort order, target texture (render UI to a RenderTexture), theme style sheet (`.tss`), clear settings, and dynamic atlas.
  - The **Panel Renderer** (6.x) and **world-space UI** (6.2+) render panels in 3D. **Panel Input Configuration** handles input routing.
- **UI Builder**: a WYSIWYG editor with Library, Hierarchy, StyleSheets, Viewport (canvas size, preview and theme) and Inspector panes, plus a UXML/USS code preview. USS variables can be edited in UI Builder (6.1).
- **USS**:
  - **Selectors**: type, `.class`, `#name`, `*`, descendant, child `>`, multiple, and pseudo-classes `:hover`, `:active`, `:inactive`, `:focus`, `:selected`, `:disabled`, `:enabled`, `:checked`, `:root`.
  - **Variables**: `--my-color: red; color: var(--my-color)`.
  - **Properties**:
    - Box model: `width`/`height`/`min-*`/`max-*`, `margin`, `padding`, `border-*-width`/`color`/`radius`.
    - Flex layout: `flex-direction`, `flex-grow`/`shrink`/`basis`, `flex-wrap`, `align-items`/`self`/`content`, `justify-content`, `position` (relative/absolute), `left`/`top`/`right`/`bottom`, `display`, `visibility`, `overflow`, `opacity`.
    - Background and color: `background-color`, `background-image` (texture, sprite, render texture, vector image, font asset), `background-position`/`size`/`repeat`, `-unity-background-scale-mode`, `-unity-slice-*` (9-slice), `color`.
    - Text: `-unity-font(-definition)`, `font-size`, `-unity-font-style`, `-unity-text-align`, `white-space`, `text-overflow`, `-unity-text-outline`, `text-shadow`, `letter-spacing`, `word-spacing`, `-unity-paragraph-spacing`.
    - Cursor and effects: `cursor`, `rotate`/`scale`/`translate`/`transform-origin`, `transition-property`/`duration`/`timing-function`/`delay` (USS transitions), and filters (6.x custom filter functions: Assets/Create/UI Toolkit/Filter Function Definition).
  - **Units**: px and %. `auto`. Length and keyword values.
- **Controls**: the element classes with `[UxmlElement]` found in the 6000.7 source are:

  BindableElement, Box, Button, RepeatButton, Toggle, ToggleButtonGroup, RadioButton, RadioButtonGroup, Label, TextElement, Image, HelpBox, Foldout, GroupBox, ScrollView, Scroller, ListView, TreeView, MultiColumnListView, MultiColumnTreeView, TabView, Tab, TwoPaneSplitView, PopupWindow, IMGUIContainer, TemplateContainer, TextField, IntegerField, LongField, UnsignedIntegerField, UnsignedLongField, FloatField, DoubleField, Hash128Field, GUIDField, Vector2Field, Vector2IntField, Vector3Field, Vector3IntField, Vector4Field, RectField, RectIntField, BoundsField, BoundsIntField, Slider, SliderInt, MinMaxSlider, ProgressBar, DropdownField, EnumField, MaskField, plus editor-only fields (ObjectField, ColorField, CurveField, GradientField, LayerField, LayerMaskField, TagField, EnumFlagsField, Mask64Field (6.1), PropertyField, InspectorElement, Toolbar*, ToolbarSearchField).
- **Events**:
  - Propagation goes trickle-down, then target, then bubble-up. Register with `RegisterCallback<T>`/`UnregisterCallback`.
  - Pointer events: PointerDown/Up/Move/Enter/Leave/Over/Out/Cancel/Capture, Click. Wheel, Key Down/Up, Navigation Move/Submit/Cancel, Focus In/Out, ChangeEvent<T>, InputEvent, GeometryChanged, AttachToPanel/DetachFromPanel, Drag and drop (DragEnter/Leave/Updated/Perform), Tooltip, ContextualMenuPopulate, Transition events.
  - **Manipulators**: `Clickable`, `ContextualMenuManipulator`, `KeyboardNavigationManipulator`, and custom `PointerManipulator`.
- **Data binding (runtime, 6.0+)**:
  - `dataSource`, `dataSourcePath`, and `SetBinding(property, new DataBinding { dataSourcePath, bindingMode })`.
  - Binding modes: TwoWay, ToTarget, ToSource, ToTargetOnce.
  - Converters (`ConverterGroup`), `[CreateProperty]`, `INotifyBindablePropertyChanged`, and custom `CustomBinding`. Editor binding uses `bindingPath` with SerializedObject.
- **Custom controls**: `[UxmlElement] public partial class MyEl : VisualElement` with `[UxmlAttribute]` fields. Custom drawing uses `generateVisualContent` + `MeshGenerationContext` / **Painter2D** (vector paths: `BeginPath`, `LineTo`, `Arc`, `BezierCurveTo`, `Fill`, `Stroke`).
- **Other features**:
  - Scheduler: `schedule.Execute(...).Every(ms)`.
  - Element animation: `experimental.animation`.
  - Styles: `ICustomStyle`, style sheet assets.
  - Render hints: `usageHints` (DynamicTransform, GroupTransform).
  - **Vector images**: the Vector Graphics module (SVG import).
  - **UI Toolkit Debugger**.
  - The UI Toolkit shader graph target (6.x).
  - **Accessibility**: screen reader support (6.x).

```csharp
using UnityEngine; using UnityEngine.UIElements;
public class MainMenu : MonoBehaviour {
    void OnEnable() {
        var root = GetComponent<UIDocument>().rootVisualElement;
        root.Q<Button>("play").clicked += () => UnityEngine.SceneManagement.SceneManager.LoadScene("Level1");
        root.Q<Slider>("volume").RegisterValueChangedCallback(e => AudioListener.volume = e.newValue);
    }
}
```

## 2. uGUI (Unity UI, `com.unity.ugui`)

- **Canvas**:
  - `renderMode`: Screen Space – Overlay, Screen Space – Camera (plane distance), World Space.
  - Settings: pixel perfect, sort order, sorting layer, target display, additional shader channels (`AdditionalCanvasShaderChannels` TexCoord1–3, Normal, Tangent), override sorting (nested canvases), and vertex color always gamma space.
  - Each Canvas has its own batch. Nested canvases isolate rebuilds, so split static and dynamic content.
- **CanvasScaler**: Constant Pixel Size, **Scale With Screen Size** (reference resolution, screen match mode Match Width Or Height/Expand/Shrink, match slider), Constant Physical Size. It also sets reference pixels per unit.
- **GraphicRaycaster** (blocking objects, blocking mask, ignore reversed graphics), `PhysicsRaycaster`, `Physics2DRaycaster`.
- **RectTransform**:
  - Geometry: anchors (min/max), pivot, anchoredPosition, sizeDelta, offsetMin/Max, rect.
  - Anchor presets (Alt/Shift to set pivot and position).
  - Editing: Blueprint mode and Raw edit mode. `ForceUpdateRectTransforms`.
- **Visual components**: `Image` (Simple, **Sliced** (9-slice), Tiled, **Filled** (Horizontal, Vertical, Radial 90/180/360, fill origin and amount, clockwise), preserve aspect, raycast target, raycast padding, maskable, pixels-per-unit multiplier), `RawImage` (UV rect), `Text` (legacy), `TextMeshProUGUI`, `Mask` (stencil), `RectMask2D` (clip with softness, padding), `Outline`, `Shadow`, `PositionAsUV1`.
- **Interaction components (Selectables)**: Button (`onClick`), Toggle (+ ToggleGroup), Slider, Scrollbar, Dropdown / TMP_Dropdown, InputField / TMP_InputField (content types, line types, character limit, validation), ScrollRect (movement type Unrestricted/Elastic/Clamped, inertia, deceleration, viewport, scrollbars).
  - Selectable **transitions**: None, Color Tint, Sprite Swap, Animation. **Navigation**: None, Horizontal, Vertical, Automatic, Explicit.
- **Layout**: HorizontalLayoutGroup, VerticalLayoutGroup, GridLayoutGroup (cell size, spacing, start corner/axis, constraint), LayoutElement (min/preferred/flexible, ignore layout, layout priority), ContentSizeFitter (Unconstrained/Min/Preferred), AspectRatioFitter (Width Controls Height, Height Controls Width, Fit In/Envelope Parent). `LayoutRebuilder.ForceRebuildLayoutImmediate`.
- **EventSystem**:
  - One EventSystem per scene, plus an input module: `StandaloneInputModule` (legacy input) or `InputSystemUIInputModule` (Input System).
  - Settings: first selected, drag threshold.
  - **Event interfaces**: IPointerEnterHandler, IPointerExitHandler, IPointerDownHandler, IPointerUpHandler, IPointerClickHandler, IPointerMoveHandler, IInitializePotentialDragHandler, IBeginDragHandler, IDragHandler, IEndDragHandler, IDropHandler, IScrollHandler, IUpdateSelectedHandler, ISelectHandler, IDeselectHandler, IMoveHandler, ISubmitHandler, ICancelHandler.
  - `EventTrigger` component.
  - Queries: `EventSystem.current.IsPointerOverGameObject()`, `RaycastAll`.

```csharp
// Draggable UI element (illustrative)
using UnityEngine; using UnityEngine.EventSystems;
public class DragMe : MonoBehaviour, IBeginDragHandler, IDragHandler, IEndDragHandler {
    RectTransform rt; Canvas canvas; CanvasGroup cg;
    void Awake() { rt = (RectTransform)transform; canvas = GetComponentInParent<Canvas>(); cg = gameObject.AddComponent<CanvasGroup>(); }
    public void OnBeginDrag(PointerEventData e) => cg.blocksRaycasts = false;
    public void OnDrag(PointerEventData e) => rt.anchoredPosition += e.delta / canvas.scaleFactor;
    public void OnEndDrag(PointerEventData e) => cg.blocksRaycasts = true;
}
```

- **CanvasGroup**: `alpha`, `interactable`, `blocksRaycasts`, `ignoreParentGroups`. Used for fading and disabling whole panels.

## 3. IMGUI

- **Entry points**: `OnGUI` runs once per event (`Event.current.type` Layout, Repaint, MouseDown, KeyDown…).
- **API**:
  - Controls in `GUI.*` and `GUILayout.*`: Button, Label, Box, TextField, TextArea, Toggle, Toolbar, SelectionGrid, HorizontalSlider, ScrollView, Window, BeginArea/Horizontal/Vertical.
  - Styling: `GUISkin`/`GUIStyle`, `GUIContent`, `GUI.matrix`, `GUI.depth`, `GUI.FocusControl`.
  - Editor variants: `EditorGUI`/`EditorGUILayout`.

## 4. Text: TextMeshPro and TextCore

- **Engine**: TextMeshPro is merged into uGUI 2.0 / TextCore in Unity 6. Modules: TextCoreFontEngine, TextCoreTextEngine.
- **Font assets**:
  - Render modes: **SDF** (signed distance field), bitmap, color (emoji).
  - Atlas: static or **dynamic**, multi-atlas, and fallback chains.
  - The **Font Asset Creator** sets sampling point size, padding, packing method, atlas resolution, character set (ASCII, extended, custom range, from file), and render mode (SDFAA, SDF8/16/32, Raster, Hinted).
- **Material presets**: outline, underlay (drop shadow), glow, bevel, lighting, and face texture.
- **Rich text tags**: `<b> <i> <u> <s> <color> <size> <font> <material> <sprite> <link> <mark> <align> <alpha> <cspace> <indent> <line-height> <margin> <mspace> <nobr> <noparse> <page> <pos> <rotate> <smallcaps> <style> <sub> <sup> <voffset> <width> <gradient> <lowercase> <uppercase> <allcaps>`.
- **Other features**: Sprite Assets (inline icons and emoji), Style Sheets, Color Gradients, text wrapping and overflow modes (Overflow, Ellipsis, Masking, Truncate, ScrollRect, Page, Linked), auto size, kerning (font features), OpenType features, character/word/line/paragraph spacing, `TMP_TextInfo` (per-character mesh access for effects), `TMP_Text.ForceMeshUpdate`, and link handling via `TMP_TextUtilities.FindIntersectingLink`.
- **Text in UI Toolkit**: uses the same TextCore engine, with Panel Text Settings, SDF/bitmap/color font assets, and advanced text generation (ICU, HarfBuzz shaping for complex scripts, 6.x).
- **Localization** (`com.unity.localization`): String Tables, Asset Tables, Smart Strings (SmartStrings module), pseudo-localization, and Localize String/Sprite/Audio/Texture/GameObject Event components (see 13).
